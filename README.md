# Smart Queue Management System (SQMS)

A web-based queue management system that allows users to generate tokens and helps staff manage queues efficiently.

## Features

- User registration and login
- Token generation and cancellation
- Real-time queue management
- Staff token management
- Token history
- User profile management
- Admin management
- Queue analytics

## Tech Stack

- **Frontend:** React, Vite
- **Backend:** Python, Flask
- **Database:** MySQL
- **Authentication:** JWT
- **Styling:** CSS
